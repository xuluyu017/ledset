/******************************************************************
                            接口说明
#注意： 下列各接口被设计为以【单实例】的方式使用，且不支持函数重入。
*******************************************************************/

1. 初始化接口
int unisound_kws_init(void);
函数说明：语音识别功能初始化。
返回值：0 - 初始化成功；
       -1 - 初始化失败；

2. 去初始化接口
int unisound_kws_deinit(void)；
函数说明：语音识别功能去初始化。执行该函数之前可以不必执行unisound_kws_stop（可以执行，但不必要）。
返回值：总是返回0

3. 模式设置接口
int unisound_kws_mode_set(engine_kws_mode mode);
函数说明：在引擎停止状态下用于唤醒模式和命令词模式的设置。
输入参数：mode - 唤醒模式（ENGINE_KWS_MODE_WAKEUP）或者命令词模式（ENGINE_KWS_MODE_CMD）。
返回值：0 - 设置成功；
       -1 - 当前为运行状态，设置失败；

4. 模式查询接口
engine_kws_mode unisound_kws_mode_get(void);
函数说明：查询当前模式。
返回值：ENGINE_KWS_MODE_WAKEUP - 唤醒模式；
        ENGINE_KWS_MODE_CMD - 命令词模式；

5. 语音识别启动接口
int unisound_kws_start(void *decoder_pool, int size)；
函数说明：启动语音识别功能
输入参数：decoder_pool - 语音识别引擎运行所需缓冲区空间，需调用者自行动态分配和释放。
         size - decoder_pool空间的大小
返回值：0 - 启动成功；
       -5 - 状态错误，当前为运行状态；
       其他 - 启动失败；

6. 语音识别停止接口
int unisound_kws_stop(void)；
函数说明：停止语音识别功能
返回值： 0 - 停止成功；
        -1 - 状态错误，当前非运行状态；

7. 语音识别执行接口
int unisound_kws_process(void *mic, kws_result_msg_t *kws_msg)；
函数说明：在语音识别启动状态下，对麦克风数据执行语音识别操作。
输入参数：mic - 输入的麦克风数据，长度固定为512字节；
         kws_msg - 输出用参数。当本函数返回值为0时，用于获取识别结果（命令词和分数）。
返回值：0 - 语音识别执行成功；
       1 - 状态错误，当前非运行状态；
       其他 - 语音识别执行失败；

8. 命令词哈希值计算
unsigned int bkdr_hash(const char* key);
函数说明：计算命令词哈希值的辅助函数，用于协助命令词查找。
输入参数：key - 语音引擎识别到的命令词，如“打开空调”。
返回值：命令词哈希值

/******************************************************************
                            使用方法举例
*******************************************************************/
【情景】
语音识别初始化并启动后，首先进入唤醒模式，被命令词唤醒后进入命令词模式。

【接口调用过程】
1. 调用unisound_kws_init，完成初始化；
2. 调用unisound_kws_mode_set，设置唤醒模式（初始化默认设置即为唤醒模式，所以这一步可选）；
3. 调用unisound_kws_start，启动语音识别；
4. 不停调用unisound_kws_process处理语音数据。这时用户说出唤醒词，可以得到相应的结果；
5. 被唤醒之后调用unisound_kws_stop停止识别，再调用unisound_kws_mode_set设置为命令词模式，然后调用unisound_kws_start重新启动语音识别；
6. 不停调用unisound_kws_process处理语音数据，并得到相应命令词识别的结果。

/******************************************************************
                          语音识别分数判别
*******************************************************************/
unisound_kws_process语音识别的结果包括命令词和分数，分别由其kws_msg参数的command和score成员表示。例如某识别结果可能为：command=“增大音量”，分数=12.5。
将分数与相应的阈值进行比较，可以判定本次语音识别是否最终匹配。

唤醒模式下，阈值由宏KWS_WAKEUP_SCORE_THRED定义（位于uni_cust_config.h中）；而命令词模式下的阈值则由宏KWS_CMD_SCORE_THRED定义（位置同前者）。
例如在命令词模式下，收到上述识别结果。则将分数12.5与KWS_CMD_SCORE_THRED比较，如果12.5>=KWS_CMD_SCORE_THRED，那么本次语音命令识别成功，否则失败。
唤醒模式下的情况类似。

/******************************************************************
                         语音识别命令词映射
*******************************************************************/
以上述识别结果为例：command=“增大音量”，分数=12.5。
当分数超出阈值时，后续代码可以根据command执行相关动作。但如果代码中不希望使用原始的“增大音量”的形式，而希望使用其对应的英文字符串，如“volumeUpUni”，
则可以借助于上述提供的命令词哈希接口计算命令词的哈希值，以此查询其对应的英文字符串。具体查询和使用方法可以参考源码包中map_command函数相关代码。
